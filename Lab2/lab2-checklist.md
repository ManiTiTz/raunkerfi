# Lab 2 — capture checklist

Working aid for *during* the lab. For how the notebook is organised overall,
see `../notebook-conventions.md`.

## Before you start
- [ ] Read the Lab 2 brief fully before touching hardware
- [ ] Note the start time (unambiguous — include AM/PM if it could be read either way)
- [ ] `mkdir ~/Lab2` on the Pi, mirroring `~/Lab1`
- [ ] Record: Pi model, OS image + version, hostname, connection method
- [ ] Note which lecture(s) this lab draws on

## Capture as it happens — not afterwards
- [ ] Exact commands, copied not paraphrased
- [ ] Exact error text, verbatim — never "it didn't work"
- [ ] Your hypothesis *before* each fix attempt, and whether it held
- [ ] Wiring: physical pin AND BCM number, plus component values
- [ ] Anything you had to look up or ask about

## Before you close the entry
- [ ] Elapsed time is arithmetically sensible
- [ ] Every "it works" has evidence — photo, output, or both
- [ ] A diagram is present (circuit, and state/timing if anything is periodic)
- [ ] Back link to the relevant lecture entry
- [ ] Someone else could reproduce your setup from these pages alone
- [ ] Pages scanned into this folder
